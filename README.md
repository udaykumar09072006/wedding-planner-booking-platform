# VendorHub – Wedding Vendor Marketplace 💍

A wedding planning and vendor booking platform designed to help couples discover wedding services, compare vendors, manage bookings, and track their wedding budget in one place.

🔗 **Live Demo:** https://applet-kappa.vercel.app/

## ✨ Features

### 1. Wedding Booking System
- Multi-step booking process with package selection and event details.
- Date validation to prevent booking conflicts.
- Couple details, guest count, and event notes.
- Transparent pricing breakdown:
  - Base package price
  - 2.5% platform concierge fee
  - 25% advance deposit
- Simulated checkout with card, UPI, net banking, and in-person consultation options.
- Booking confirmation with a unique reference ID.
- Booking state persistence and calendar availability management.

### 2. Vendor Comparison
Compare 2–4 wedding vendors side by side based on:
- Ratings and starting prices
- Location and response time
- Experience and available packages
- Amenities and direct booking options

### 3. Couple Dashboard
- **My Bookings:** View booking statuses, receipts, and cancellation options.
- **Wedding Countdown:** Track the days remaining until the wedding.
- **Milestone Checklist:** Organize venue, photography, beauty, catering, and music tasks.
- **Budget Tracker:** Monitor committed costs, deposits paid, and remaining balances.

### 4. Vendor Dashboard
- **Analytics:** Track inquiries, active bookings, contracted revenue, and average ratings.
- **Inquiry Management:** Accept, decline, or mark requests as completed.
- **Listing Editor:** Update business details, pricing, taglines, and descriptions.
- **Calendar Management:** Block or unblock unavailable dates.
- **Review Responses:** Reply to client reviews.

### 5. Authentication & User Experience
- Separate Couple and Wedding Vendor experiences.
- One-click demo access for quick testing.
- Dark mode with theme preference persistence using `localStorage`.
